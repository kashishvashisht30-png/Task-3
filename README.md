# Task-3
# Airbnb Listing Segmentation using K-Means Clustering

This project demonstrates the application of **Unsupervised Machine Learning** techniques to segment Airbnb listings into meaningful groups using the **New York City Airbnb Open Dataset (AB_NYC_2019)**. The objective is to discover hidden patterns in listing data and gain insights that can support business decision-making, pricing strategies, and customer segmentation.

## Project Overview
The project follows a complete machine learning workflow, including:

* Data Cleaning and Preprocessing
* Missing Value Handling
* Feature Selection and Engineering
* Categorical Data Encoding
* Feature Scaling using StandardScaler
* K-Means Clustering Implementation
* Optimal Cluster Selection using the Elbow Method
* Cluster Visualization and Analysis
* Business Insight Generation

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Key Features

* Processed and analyzed 48,000+ Airbnb listings.
* Applied K-Means Clustering to identify distinct property segments.
* Used the Elbow Method to determine the optimal number of clusters.
* Visualized cluster distributions and patterns through graphs and plots.
* Interpreted cluster characteristics to derive meaningful business insights.

## Business Applications

The clustering results can help:

* Hosts optimize pricing and availability strategies.
* Businesses understand different property segments.
* Researchers analyze accommodation and tourism trends.
* Recommendation systems provide personalized property suggestions.
